# Adam-zat Game 🎮

**Adam-zat Game** — бұл қазақ тілін үйренуге және сөздік қорды байытуға арналған қызықты білім беру ойыны.

## 🚀 Жоба туралы
Бұл жоба пайдаланушыларға сөздермен жұмыс істеу, жаңа сөздер үйрену және басқа ойыншылармен жарысуға мүмкіндік береді. Ойын заманауи технологиялармен құрылған және мобильді құрылғыларда жұмыс істейді.

## ✨ Негізгі мүмкіндіктері
- **Ойын бөлмелері:** Жаңа бөлме құру немесе қолданылған бөлмеге қосылу мүмкіндігі.
- **Көшбасшылар кестесі (Leaderboard):** Ең үздік ойыншыларды көру және олармен жарысу.
- **Жеке профиль:** Пайдаланушы мәліметтерін басқару және жетістіктерді бақылау.
- **Сөздер базасы:** Қазақ тіліндегі бай сөздік жинағы.
